# Architecture-to-Code Mapping (Post-Refactor)

**Paper:** Digital Twins for Uncertainty Mitigation in Self-Adaptive Smart City IoT Systems  
**Venue:** IoT '26 — 16th International Conference on the Internet of Things  

This document cross-references every paper-defined architectural component against the modular files in this repository following the architectural refactoring to single-responsibility (SRP) modules.
